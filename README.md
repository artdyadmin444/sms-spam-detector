# SMS Spam Detector — Flask + ML + Deep Learning

## Features
- Real-time SMS prediction endpoint
- Naive Bayes, Logistic Regression, Deep Learning adapter
- SQLite prediction history (SMS text is NOT stored)
- Metrics/report page (only metrics generated by the evaluation endpoint are displayed)
- Admin login and audit log
- Responsive Bootstrap UI
- Evaluation uses one deterministic stratified train/test split for the scikit-learn models

## 1. Requirements
Python 3.10–3.12 recommended. TensorFlow support varies by OS/Python version; if TensorFlow install fails, use a supported Python version or temporarily omit it while evaluating ML models.

## 2. Install
Windows PowerShell:
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
```
Edit `.env`, set a long random `FLASK_SECRET_KEY` and a unique `ADMIN_PASSWORD`.

macOS/Linux:
```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
```

## 3. Add dataset
Download the UCI SMS Spam Collection zip from:
https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip
Extract `SMSSpamCollection` into `data/SMSSpamCollection`.
The evaluation reader expects a tab-separated file with label (`ham` or `spam`) followed by message. Do not add a dataset downloaded from an untrusted source.

## 4. Export existing Google Colab models
The app intentionally does not fabricate metrics or claim your old Colab model is available. You must export trained artifacts.
- scikit-learn: either train and export via `python export_models.py` (this trains baseline models using the local dataset), or sign in as Admin and click “Evaluate & save baselines” to evaluate and save the ML pipelines.
- Deep Learning: from Colab, save your trained Keras model using `model.save("deep_learning.keras")`, then download that file and place it in `models/deep_learning.keras`. The saved model must accept raw text strings and output one sigmoid probability where 1 means SPAM. If your model has a separate `TextVectorization` layer or uses integer vectors, adapt `ModelService._predict_dl` to match the exact Colab preprocessing. Never assume the exported model is compatible without checking.
- The metrics page only displays evaluated ML metrics generated on the same held-out split. DL metrics are intentionally not recorded until its evaluation path is implemented against the same exact split and preprocessing.

## 5. Run
```bash
python app.py
```
Open http://127.0.0.1:5000
Admin: http://127.0.0.1:5000/admin/login

## Privacy / deployment
- Prediction history stores label, confidence, model version, timestamp, text length and SHA-256 digest; not the message body. Note: hashes can still be linkable for repeated messages.
- Set `COOKIE_SECURE=1` behind HTTPS.
- Do not expose Flask's development server publicly. Use a production WSGI server and HTTPS for deployment.
- Add CSRF protection and rate limiting before public internet deployment.
- The sample admin login should be enhanced with CSRF protection and rate limiting before deployment.
